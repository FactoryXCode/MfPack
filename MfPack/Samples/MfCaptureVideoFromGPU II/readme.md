# MfCaptureVideoFromGPU II

&#x20; 

Version: 4.1.0  

&#x20; 

Description:  
Demonstrates how to capture from screen using your videocard GPU and sound  
using Audio Loopback.  

&#x20; 

NOTES:

* This release is updated for compiler version 28.0 up to 36.0.
* SDK version: 10.0.28000.2705 (Win 11)
* Requires Windows 10 or later.
* Minimum supported MfPack version: 4.1.0

&#x20; 

&#x20; 

\*\*What it does:\*\*

Captures a selected monitor using DXGI Desktop Duplication, optionally captures system audio via  
WASAPI loopback, shows a live preview, and writes the result to a file (typically MP4 with H.264 video  
and AAC or FLAC audio). Audio-only recording can be done separately to WAV or FLAC using the  
dedicated recorder unit.

The application is kept as simple as possible to show you the workflow and concepts of screen capturing and  
catching sound from an audiodevice, to a MP4 file and preview screen.
