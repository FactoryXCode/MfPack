1 - Create a fiolder on the server/pc you want Fxserve to run on.
For example C:\FxServe.
2 - Copy our compiled version of FxServe (FxServe.exe) in to the  C:\FxServe folder.
3 - Unpack the contents of FxServe-www.zip in the FxServer folder on your server or local PC,
so it becomes: C:\FxServe\www
4 - Start your compiled verion of FxServeAdmin and set FxServe up for running.

Note:
Do not copy FxServeAdmin to the same folder, always keep this app local on 
the same pc RDJ or RDJ Pro is running on.
FxServeAdmin should be started with Admin rights.
